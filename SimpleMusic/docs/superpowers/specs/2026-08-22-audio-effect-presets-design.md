# DiskTone 扩展音效预设设计

日期：2026-08-22

## 目标

在不改变现有页面导航、播放队列和系统音乐播放架构的前提下，为下载歌曲新增四种可辨识的音效：全景环绕、摇滚经典、动感电音和清晰人声。同时将顺序播放图标的颜色统一为主题红色，使三种播放模式具有一致的视觉状态。

## 范围与边界

- 新音效只处理 App 下载并由本地播放后端读取的歌曲。
- 系统音乐库继续由 `MPMusicPlayerController` 播放，无法插入 App 自己的 EQ 或混响节点，因此保持原始输出并沿用现有不可用提示。
- “全景环绕”是立体声拓宽的听感模拟，不提供 Dolby Atmos、头部追踪或多声道输出。
- 保留关闭、小房间、中房间、大房间、中厅、大厅、教堂和板式混响等现有预设。
- 不增加第三方音频依赖，继续使用 AVFAudio。
- 不修改播放队列、播放模式顺序、远程控制、下载队列或 Core Data。

## 方案选择

采用统一的 `AVAudioUnitEQ + AVAudioUnitReverb` 音效链。

未采用仅重命名混响预设的方案，因为摇滚、电音和人声需要不同的频率响应，单独调整混响无法形成稳定可辨识的听感。未引入第三方 DSP，因为本次需求可由系统音频单元完成，引入新依赖会扩大包体、兼容性和播放生命周期风险。

## 领域模型

`AudioEffectPreset` 新增四个稳定 raw value：

- `panoramicSurround`
- `classicRock`
- `dynamicElectronic`
- `clearVocal`

现有 raw value 保持不变，`SettingsStore` 继续存储预设 raw value 和强度值，因此无需数据迁移。旧版本保存的设置仍可正常恢复，无法识别的值继续回退到 `.off`。

`AudioEffectSettings.wetDryMix` 为保持持久化与调用方兼容而保留字段名。界面统一把它解释为 0～100 的“音效强度”：

- 现有混响预设：数值继续直接控制 `AVAudioUnitReverb.wetDryMix`。
- 新组合预设：数值按百分比缩放 EQ 增益和该预设的最大混响比例。
- 关闭：EQ 旁路，混响比例为 0。

## 音频处理链

本地音效播放器调整为：

`AVAudioPlayerNode → AVAudioUnitEQ → AVAudioUnitReverb → mainMixerNode`

播放器仍由现有本地后端持有 generation、播放进度、文件 lease、暂停、跳转和完成回调。切换关闭/开启音效时继续沿用当前 AVPlayer 与 AVAudioEngine 之间的进度接续逻辑；音效引擎启动失败时继续回退到原始 AVPlayer 播放，不中断歌曲。

为了避免名称与职责不符，内部 `ReverbAudioPlaying`/`SystemReverbAudioPlayer` 将重命名为通用音效播放器命名，但不向 UI 或其他模块暴露新架构。

## 预设参数

组合预设以 `强度 / 100` 作为缩放系数。以下数值为强度 100 时的目标值；降低强度会按比例减小增益和混响，不做突变开关。

### 全景环绕

- 低架 120 Hz：+1.5 dB
- 参数均衡 600 Hz：-1.5 dB
- 高架 7 kHz：+2 dB
- `largeRoom` 立体声混响：最高 30%

该预设通过降低中低频拥挤、增强两端空气感并加入较宽的系统立体声反射，模拟更开阔的声场；不宣称改变原始声道数量。

### 摇滚经典

- 低架 90 Hz：+3 dB
- 参数均衡 300 Hz：-1 dB
- 参数均衡 1.8 kHz：+2.5 dB
- 高架 6 kHz：+2 dB
- `plate` 混响：最高 12%

重点突出底鼓、贝斯、吉他存在感和镲片清晰度，同时避免中低频过度浑浊。

### 动感电音

- 低架 70 Hz：+4 dB
- 参数均衡 500 Hz：-2 dB
- 高架 8 kHz：+3 dB
- `plate` 混响：最高 16%

形成更明显的低频冲击和高频亮度，并给合成器留出中频空间。

### 清晰人声

- 参数均衡 250 Hz：-2 dB
- 参数均衡 2.5 kHz：+3 dB
- 高架 6 kHz：+2 dB
- `smallRoom` 混响：最高 8%

减少人声低频浑浊，增强咬字与空气感，混响保持克制。

所有 EQ 增益保持在温和范围，避免新增限幅器或压缩器，也避免明显削波。系统混响预设和最大混响比例作为预设配置集中维护，不散落在 UI 中。

## 界面与本地化

- 音效页面继续使用当前列表和强度滑块，不改变导航方式。
- 四个组合预设排列在“关闭”之后，现有空间混响预设随后显示。
- 新增简体中文、繁体中文和英文名称。
- 当前不可用提示继续明确说明系统音乐不支持 App 音效。
- 顺序播放、单曲循环、随机播放三种模式图标统一使用 `Theme.accent`；图标和切换顺序不变。

## 状态更新与持久化

用户选择预设或调整强度后，沿用现有调用链：

`AudioEffectsViewController → AppCoordinator → PlaybackCoordinator → LocalPlaybackBackend`

`PlaybackCoordinator` 更新快照并将设置交给本地后端，`SettingsStore` 保存最新设置。当前下载歌曲正在通过音效引擎播放时，EQ 和混响参数原地更新；从关闭切换为任意音效或从音效切回关闭时，继续按现有时间点切换传输实现。

## 错误与回退

- 音效引擎加载文件、连接节点或启动失败：回退原始本地播放，并保留歌曲进度。
- 预设配置缺失：视为关闭，避免使用未初始化的频段。
- 系统音乐：禁用音效选择，保持当前提示，不尝试抓取或重编码系统输出。
- 强度越界：继续由 `AudioEffectSettings` 限制在 0～100。

## 验证

- 领域测试验证四个新 raw value、强度限幅和旧设置兼容。
- 音效配置测试验证四种预设对应的 EQ 频段、目标增益、混响预设和最大比例。
- 本地后端生命周期测试验证播放中更新、关闭/开启切换、seek、完成回调和引擎失败回退。
- UI 测试验证四个名称可见、选择后发布正确设置，并验证系统音乐保持不可用。
- 播放器测试验证顺序、循环、随机三种模式的图标颜色均为主题红色。
- 最终运行相关 focused tests、完整 XCTest，以及 generic iOS Simulator/device build。

## 不在本次范围

- 真正的多声道环绕、Dolby Atmos 和头部追踪。
- 用户自定义 EQ 频段。
- 音效应用到系统音乐库歌曲。
- 动态压缩、限幅、失真或节拍检测。
